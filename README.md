# ネオン ロボファーム 〜 かみなりで めざめた ロボと さびれた むら 〜

Stardew Valley・牧場物語のような、こども向けの 2D ドット絵ゲーム。タブレットのブラウザで動く（十字キー＋Aボタン）。
主人公はロボット。さんすうアプリの「実力テスト」の点数が、ロボの **でんち🔋** になる（テストをやると かみなりが落ちて じゅうでん される）。つなぎ方は [BRIDGE.md](BRIDGE.md)。

## おはなし

だれもいなくなった さびれた むら。はかせの家のすみで、1台のロボが とまっていた。じゅうでんきは こわれていて、でんちは からっぽ。

- はじめて遊ぶと、ロボは とまったまま（画面が暗く、うごかせない）。「さんすうアプリで じつりょくテストを やってみよう」と出る
- さんすうアプリで **はじめて実力テストをやると**、やねのアンテナに かみなりが落ち、じゅうでんきに でんきが流れて ロボが めをさます（点数ぶん じゅうでん）
- そのあとも、実力テストの点数が届くたびに かみなりが落ちて じゅうでん される
- 保護者のデバッグ（あいことば `claude`）の端末では、テストなしで めをさます

タイトル画面はサイバーパンク風（よるの むらと ネオン）。むらには人がいないので、お店は しゃべらない **じどう はんばいき**。

## あそびかた（いまできること）

1. **いえを かたづける**：はかせの ほこりだらけの家。がらくた（10こ）を Aで持ち上げ、たんすに しまう。
   しまうほど家が明るくなり、とちゅうで **ぼろい パーツ** と道具が見つかる。10こめで はかせの手紙（50G）。
   つりざおを見つけるまでは外に出られない。

| しまった数 | 見つかるもの |
|---|---|
| 2 | パーツ「ガタガタ キャタピラ」（あし） |
| 3 | ぼろい つりざお |
| 5 | パーツ「さびた アンテナ」（センサー） |
| 6 | ちいさな むしあみ |
| 8 | さびた くわ |
| 9 | パーツ「ギシギシ アーム」（うで） |
| 10 | はかせの手紙・50G |

2. **つりで おかねを かせぐ**：池の前で つりざおを使う → 魚が寄ってくる → うきが2〜3回「ツン」と小さく沈む（前あたり。ここで A を押すと逃げる）→ スパッと全部沈んだら すぐ A（本あたり。押せるのは 0.4〜0.7秒で、大きい魚ほど短い。アンテナがあると +0.2秒）→ メーターの みどりで A。
   釣っている間は 右上に「上から見た水の中」のカットインが出て、魚影が寄ってくる・エサをつつく・食いついて走る・暴れる 様子が見える（`cutin.js`）。前あたりの回数や間は `config.js` の `CFG.approach`・`nibbles`・`nibbleGap`・`biteDelay`、魚ごとの本あたりの時間は `FISH` の `bite`。
   ぼろい つりざおは メダカ・タナゴ・フナ・ドジョウ。ふつうの つりざお（600G）で コイ・ナマズ・ウナギ。たまに あきかん・ながぐつ。
   釣った魚は 家の横の **しゅっかばこ** で売る。🎒の「さかな ずかん」に記録が残る。
3. **はたけを ひらく**：さくの中の くさを くわで かり、たがやす。いしは うでのパーツ（ギシギシ アーム）がないと どかせない。じどう はんばいきで **じょうろ（150G）** と たねを買う。
   たねをまき、毎日 じょうろで水をあげ、ベッドで スリープ すると1日進む。水をあげた日だけ育つ（かれることはない）。

| やさい | たね | そだつ日数（水やり） | 売ると |
|---|---|---|---|
| かぶ | 20G | 3 | 50G |
| にんじん | 35G | 4 | 85G |
| トマト | 60G | 6 | 170G |
| かぼちゃ | 110G | 8 | 340G |

## ロボの パーツ

パーツをよくすると ロボの性能が上がり、できることが増える。🎒の「ロボの パーツ」で見られる。つけたパーツで ロボの見た目も変わる（キャタピラ・大きなアーム・ピンクに光るアンテナ）。
ルールは `config.js` の `PARTS`（名前）と `PART_FX`（ちから）。

| パーツ | Lv 0（はじめから） | Lv 1（ぼろい・かたづけで見つかる） |
|---|---|---|
| あし | ちいさな タイヤ：ゆっくり（1秒に3.6マス） | ガタガタ キャタピラ：1秒に5.2マス |
| うで | ほそい うで：かるい物だけ | ギシギシ アーム：はたけの いしを どかせる |
| センサー | こわれた アンテナ | さびた アンテナ：つりの本あたりが0.2秒長い |

- これから：Lv 2（ふつう）は たんけんで見つかるようにする。ふつう より上は そざいを集めてレベルアップ

## さんすうアプリとの いききする ボタン

- ゲーム → さんすうアプリ：タイトルの「🧮 さんすうアプリに もどる」と、☰メニューの「🧮 さんすうアプリに もどる」（セーブしてから もどる）。ロボが とまっている間の おしらせにも ボタンがある。行き先は `config.js` の `CFG.mathUrl`（`../math-app/`）
- さんすうアプリ → ゲーム：ホームの上の「🤖 ネオン ロボファーム」と、実力テストの結果の「🤖 ロボファームで あそぶ」

## でんち🔋

- 実力テストの点数ぶん じゅうでん（1日1回・最高150。上限1050＝1週間分ためられる）。はじめは 0
- 上のバーは1日分（150）で いっぱい。それより多い分は数字で見る
- 保護者のデバッグ：さんすうアプリの保護者メニューで あいことば `claude` を入れた端末では、でんちが へらない（「∞」と出る）
- **スリープ（寝る）しても増えない**。足りないと「さんすうアプリで実力テストをやろう」と出る
- 減る量：がらくたを持ち上げる 1、つりざおを投げる 3、くさを かる 2、いしを どける 4、たがやす 3、たねまき 1、みずやり 2
  （歩く・売る・買う・スリープ・しゅうかく は0）。`config.js` の `CFG.cost` で変えられる

## セーブ

- `mathapp.v1.game.save.<子供のid>`。ロボのおはなしにしたときに版を 2 にした（`bridge.js` の `SAVE_V`）。前の「おじいちゃんの いえ」の記録（版 1）は使わず、みんな さいしょから

## そうさ

- タブレット：左下の十字キー（指をすべらせて向きを変えられる）・右下の Aボタン・下のホットバーで道具をえらぶ。短く押すと向きだけ変わる
- キーボード：矢印 / WASD で移動、Space / Enter / Z で A、Q・E か 1〜9 で道具、Esc でとじる

## ファイル

| ファイル | 中身 |
|---|---|
| `config.js` | 数字とルール（でんち・パーツ・魚・やさい・がらくた・見つかる道具とパーツ）。調整はここ |
| `bridge.js` | さんすうアプリとのつなぎ・セーブ |
| `sprites.js` | ドット絵（1マス32ドット・ふちどり・光と影。画像ファイルなし、すべてプログラムで描く。地面は1枚の絵に焼き込む）。ロボはパーツの組み合わせごとに作る（`robotSpr`） |
| `world.js` | マップ（家の中 14×10、外 40×28） |
| `ui.js` | 会話・お店・もちもの・効果音（WebAudio。かみなり・きどう音も） |
| `cutin.js` | 釣りのカットイン（上から見た水の中・魚影・うき） |
| `game.js` | おはなし（めざめ・かみなり）・移動・片付け・釣り・畑・スリープ・描画 |

## ためす

```
python -m http.server 8770 --bind 127.0.0.1
```

`http://localhost:8770/?dev=1` で開くと、☰メニューに おとな（テスト）メニュー（かみなりで でんち+50を届ける・+500G・でんち むげん・家をぜんぶ片付ける）が出る。とまっているロボも「+50を届ける」で めをさます。
