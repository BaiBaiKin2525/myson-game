# ネオン ロボファーム 〜 100年目の ロボットと ネオンの町 〜

『Stardew Valley』『牧場物語』のような、子供向けの2Dドット絵ゲーム。タブレットのブラウザで動く(十字キー＋Aボタン)。
算数アプリの「実力テスト」の点数が、ロボットの **電池🔋(算数エネルギー)** になる。つなぎ方は [BRIDGE.md](BRIDGE.md)。

世界観と全5章の流れは、Gemini と詰めた資料(`robita_game_setting.md`)をもとにしている。決めたことは [DESIGN.md](DESIGN.md)。**いま遊べるのは2章まで**。

## おはなし

西暦21XX年。青く光るばいきん「ネオンスポア」が町じゅうに増え、人間の頭の中の「でんのう」を固める病気がはやった。人間たちは、ばいきんの届かない空の上のコロニーへ引っこした。

それから100年。だれもいない研究室の奥で、古いロボットが1台、電池切れで止まっていた。古い機械式のロボットなので、でんのうが固まる病気にはならない。ただし体にネオンスポアがくっつくと動きが遅くなるので、植物からしぼる「バリアオイル」をぬって守る。

- はじめて遊ぶと、ロボットは止まったまま(画面が暗く、動かせない)。「算数アプリで じつりょくテストを やってみよう」と出る
- 算数アプリで実力テストをやると、じゅう電きに電気が流れて目をさます(点数ぶん じゅう電)。そのあとも点数が届くたびに じゅう電される
- 目をさましたら、**子供がロボットに名前をつける**(ひらがな・カタカナのボタン、6文字まで。最初に入っているのは「ロビタ」)。会話の `{name}` がこの名前になる
- 博士は100年前のビデオ(録画)だけで登場する。研究室のメインパネルで再生され、あとから見直せる

## 文字(漢字とふりがな)

- 小学2年生までに習う漢字だけを使い、**すべての漢字にふりがな**を付ける。漢字を使わず、ひらがなのままの文もある
- 書き方：文の中に `{漢字|かんじ}` と書くと、ふりがな(ルビ)つきで出る(`ui.js` の `rt`・`rbh`)。canvas の文字(`addFx`)は読みだけを出す
- 小2より上の漢字や、ふりがなを付け忘れた漢字がないかは、文字列を調べるスクリプトで確かめている

## 1章：100年目の さいきどう(研究室)

研究室の4つの機械を順番に直す。直すたびに博士のビデオが1本見られる。HUD の「🎯」に、次にやることと足りない材料が出る。順番と材料は `config.js` の `CH1`。

| 順 | 直すもの | 材料 | 電池🔋 | できるようになること | ビデオ |
|---|---|---|---|---|---|
| 1 | かべの メインパネル | なし | 10 | 研究室の明かりがつく。ビデオが見られる | 01「おはよう」 |
| 2 | しつない プランター(4つ) | てつくず2 | 5 | オイル草のたね3・かぶのたね2・じょうろ をもらう。たねをまいて育てる | 02「はじめての はたけ」 |
| 3 | オイル しぼりき | ねじ1 | 5 | オイル草2本 → バリアオイル。もちもの🎒から体に「ぬる」 | 03「バリアオイル」 |
| 4 | サイバーか そうち(治療ポッド) | ねじ2・てつくず4 | 15 | 直すと「きれいな水がない」とわかる → **1章クリア** | 04「サイバーか そうち」 |

- サイバーか そうち は、はじめてバリアオイルをぬってからでないと直せない
- 材料(てつくず・ねじ)は、研究室のガラクタや道に落ちている「こわれた きかい」を **ごうせい そうち** に入れると出る
- 1章クリアのあと スリープ ポッドで寝ると、つぎの朝から2章がはじまる

### しつない プランター

- 研究室の下の真ん中に4つ。たねを選んでA → じょうろで水 → スリープ ポッドで寝ると1日進む。水をあげた日だけ育つ(かれない)
- **ひりょう(あぶらかす)** をまくと、水をあげた日に2日分育つ(`KASU_BOOST`)
- 外の畑は、ネオンスポアが濃くて1章ではまだ使えない(2章で開く。くわ・じょうろ・たね・ひりょうが使える)

| たね | 育つ日数(水やり) | 使いみち |
|---|---|---|
| オイル草 | 3 | 2本で バリアオイル(🛢+40) |
| ごま | 5 | 2こで ごまの バリアオイル(🛢+60) |
| ネオンひまわり(2章) | 5 | 1つで ひまわりの バリアオイル(🛢+45) |
| ライトかぶ・でんきニンジン(2章)・にんじん・トマト・かぼちゃ | 3・4・4・6・8 | 3章から売ったり動物のえさになる予定。いまは ごうせい そうちに入れると たねが出ることがある |

- オイル草は青く光る草、かぶは ほんのり光る「ライトかぶ」(2章で描きなおし)
- 2章からは、ごうせい そうちから ライトかぶ・でんきニンジン・ネオンひまわりの たねも出る

### 外：あれはてた町と よごれた水ろ

- 100年だれもいない町。緑はほとんどなく、枯れ草とむき出しの土、ひび割れたアスファルト(消えかけた線)、コンクリートの水ろの岸
- 北には崩れたビル(割れた窓・板でふさいだ窓・半分消えたネオン看板)、南には崩れた壁・廃車・がれき、まわりに枯れ木・ドラム缶・壊れた街灯。調べる(A)と ひとこと出る(`ACT.look`)
- 4章の空気浄化ツリーで緑がもどる予定(`m.ruin` が `flags.airClean` で切りかわる。地面の色・置く物が変わる)

- 研究室の東に、北から南へ流れる水ろがある。ネオンスポアで **むらさきと水色に光っている**。外にはネオンスポアがふわふわ飛んでいる
- 釣れる魚は **光るすがた** だけ(光るメダカ・光るタナゴ・光るフナ・光るドジョウ)。ネオンスポアがくっついていて、オイルはとれない
  - ごうせい そうちに入れると **あぶらかす(ひりょう)** が出る
  - ラボ図かん(🎒)に「光るすがた」としてのる。「もとのすがた」は2章で水ろがきれいになると会える
- たまに「水ぞこの きかい」(こわれた きかい)や ながぐつが釣れる
- 釣り方は前と同じ：魚が寄ってくる → ウキが2〜3回「ツン」(前あたり。ここでAを押すと逃げる)→ スパッと沈んだらすぐA(本あたり)→ メーターの緑でA。右上に上から見た水の中のカットインが出る(`cutin.js`)
- 外にはオイル草が2本さいている(とると3日でまた咲く)。水ろの「ろかそうち」は、こわれていて2章で直す

## 2章：ネオン水ろの じょうか(研究室まわりと海)

HUD の「🎯」に次にやることが出る。数字は `config.js` の `CH2_SEEDS`・`FILTER_FIX`・`OTTER_HEAL`・`OTTER_GIFT`。

| 順 | やること | くわしく | ビデオ |
|---|---|---|---|
| 0 | はじまり | 1章クリアのつぎの朝。さびた くわ・でんきニンジンのたね3・ネオンひまわりのたね3 をもらい、外の畑が使えるようになる | 05「外の はたけ」 |
| 1 | はぐるまを釣る | よごれた水ろで、光る魚にまじって **さびた はぐるま** が釣れる(3こ そろうまで) | |
| 2 | ろかそうちを直す | はぐるま3・ねじ2・てつくず3・どれかの バリアオイル1・電池🔋20。水ろと海の水がきれいになり、南の がれきが流されて **海へ行ける** | 06「きれいな 水」 |
| 3 | きれいな水で釣る | メダカ・タナゴ・フナ・ドジョウ・メダカッチ・オイルフィッシュ・ネオン金魚・カワウソエビ。はじめて釣ると ビデオ | 07「水ろの 魚」 |
| 4 | カワウソを たすける | 水ろの岸に よわった カワウソがたおれている。だっこして(研究室にしか入れない)サイバーか そうちで治す(電池🔋20) | 08「さいしょの なかま」 |
| 5 | 2章クリア | カワウソは水ろのそばにいる | |

- **カワウソ**：調べて魚をあげると、つぎの朝に畑とプランター(育ちきっていないもの)に水をまいてくれる。ときどき魚をおすそわけ(ふつう35%、大好物のカワウソエビ・メダカッチをあげた日は70%)。「〜だプイ！」
- **海**：ていぼうの上からだけ釣れる。ネオンアジ・ピカハゼ・エレキガニ・ネオンダコ。しお風でオイルが2倍へる
- **オイルフィッシュ** 1ぴき → さかなの バリアオイル(🛢+35)
- ラボ図かんの魚のページは「光るすがた」「水ろの魚」「海の いきもの」の3つ

## 町の地図とエリア(DESIGN.md「全体マップ」)

水ろが町の背骨。上流は鉱山、下流は海。エリアの端まで歩くと、となりのエリアへ切りかわる(端の道の上ならどこからでも)。水ろと川ぞいの道は、エリアの端で切れずにつながる。設定は `config.js` の `AREAS`・`GATES`、マップは `world.js` の `AREA_BUILD`。

| エリア | 行ける章 | いま |
|---|---|---|
| ネオン こうざん(上流) | 4 | まだ作っていない |
| スカイステーション | 5 | まだ作っていない |
| ちゅうおう広場 | 3 | からっぽの形：石だたみの広場、かれた空気じょうかツリー、こわれたベンチ、からっぽの果樹園。北は鉱山、東は橋をわたって商店街へ(どちらも ふさがっている) |
| ネオン しょう店がい | 3 | まだ作っていない |
| 研究室まわり | 1 | 北の道は広場へ(3章まで ふさがっている)、南の道は海へ(2章で ろかそうちを直すまで ふさがっている) |
| 海と みなと(下流) | 2 | からっぽの形：水ろが海へ流れこむ。コンクリートの岸ぺき、海につきでた ていぼう、こわれたボート。**しお風でバリアオイルが2倍へる**(`SEA_OIL`)。ボートがないうちは ていぼうの上からだけ釣れる |

- **ふさがった道**：道の上はバリケードと こいネオンスポアの霧(光る)、その行(列)の ほかのマスは がれきで、横から回りこめない。となりのエリアへの出口でも章を確かめる。まだ入れないエリアや がれきの向こうにいたら(前の版で回りこめていたとき)、研究室の前など もどれる場所へ動かす(`rescue`)。調べると「○章で通れる」とわかる。章(`save.ch`)が進むと自動でなくなる
- **町の地図**：上の🗺ボタン。いる所・行ける所・まだ行けない所(🔒○章)が出る。`?dev=1` のときは、行きたいエリアをタップするとそこへ行ける
- そとのエリアは、はじめて入るときにマップを作る(地面を焼くのに少し時間がかかるため、まとめて作らない)
- 1章ではまだ広場にも海にも行けない(海は2章の ろかそうちのあと)。☰の おとなメニュー「ふさがった みちを ぜんぶ ひらく(テスト)」で見られる

| 2 | パーツ「ガタガタ キャタピラ」(あし) |
| 3 | ぼろい つりざお(これが出るまで外に出られない) |
| 5 | パーツ「さびた アンテナ」(センサー) |
| 6 | オイル草のたね2 |
| 8 | ごまのたね2 |
| 9 | パーツ「ギシギシ アーム」(うで) |

| 入れるもの | 出るもの |
|---|---|

| ほかのガラクタ | てつくず 40%・たね 25% |

## バリアオイル🛢

- ロボットのオイル(0〜100、はじめは40)。1マス歩くと 0.08、道具を使うと 0.3、1日(スリープ)で 10 へる(`CFG.oil`)
- 資料どおり：**50より少ないと**体にネオンスポアがくっついて光りはじめ(減るほど多く光る)、上の🛢が赤くなる。**0になると**歩くのが目に見えて遅くなり(0.45倍)、ギギギと音がする。止まって動けなくなることはない(`CFG.oilGlow`・`CFG.oilSlow`)

## ロボの パーツ

パーツをよくするとロボの性能が上がる。🎒の「ロボの パーツ」で見られ、つけたパーツで見た目も変わる。ルールは `config.js` の `PARTS` と `PART_FX`。

| パーツ | Lv 0(はじめから) | Lv 1(ぼろい・かたづけで見つかる) |
|---|---|---|
| あし | ちいさな タイヤ：ゆっくり(1秒に3.6マス) | ガタガタ キャタピラ：1秒に5.2マス |
| うで | ほそい うで：かるい物だけ | ギシギシ アーム：重い石も どかせる |
| センサー | こわれた アンテナ | さびた アンテナ：釣りの本あたりが0.2秒長い |

## 電池🔋(算数エネルギー)

- 実力テストの点数ぶん じゅう電(1日1回・最高150。上限1050＝1週間分ためられる)。はじめは 0
- 上のバーは1日分(150)で いっぱい。それより多い分は数字で見る
- 保護者のデバッグ：算数アプリの保護者メニューで あいことば `claude` を入れた端末では、電池がへらない(「∞」と出る)
- **スリープ(寝る)しても増えない**。足りないと「算数アプリで実力テストをやろう」と出る
- 減る量：ガラクタを持ち上げる・ごうせい そうちに入れる・しぼる・ひろう 1、つりざおを投げる 3、たねまき 1、水やり 2、機械を直す 5〜15(`CH1`)。`config.js` の `CFG.cost` で変えられる

## 算数アプリとの行き来

- ゲーム → 算数アプリ：タイトルと☰メニューの「🧮 さんすうアプリに もどる」(メニューからはセーブしてから戻る)。行き先は `CFG.mathUrl`(`../math-app/`)
- 算数アプリ → ゲーム：ホームの上のボタンと、実力テストの結果のボタン

## セーブ

- `mathapp.v1.game.save.<子供のid>`。ロビタの世界観にしたときに版を 3 にした(`bridge.js` の `SAVE_V`)
- 前の版のセーブは使わず最初から。ただし **ためた電池と、取りこんだ届けの記録は引きつぐ**(同じ届けが2回入らない)。電池が残っていれば、オープニングのあとすぐ目をさます

## そうさ

- タブレット：左下の十字キー(指をすべらせて向きを変えられる)・右下の Aボタン・下のホットバーで道具をえらぶ。短く押すと向きだけ変わる
- キーボード：矢印 / WASD で移動、Space / Enter / Z で A、Q・E か 1〜9 で道具、Esc でとじる

## ためす

```
python -m http.server 8770 --bind 127.0.0.1
```

`http://localhost:8770/?dev=1` で開くと、☰メニューに おとな(テスト)メニューが出る：電池+50を届ける・ねじ+3／てつくず+8・オイル100・電池むげん・研究室をぜんぶ片付ける・1章の機械をぜんぶ直す・2章をはじめる・さびた はぐるま+3とバリアオイル+1。止まっているロボも「+50を届ける」で目をさます。
