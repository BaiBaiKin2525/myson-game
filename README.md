# おじいちゃんの いえ 〜 つりと はたけの ものがたり 〜

Stardew Valley・牧場物語のような、こども向けの 2D ドット絵ゲーム。タブレットのブラウザで動く（十字キー＋Aボタン）。
さんすうアプリの「実力テスト」の点数が、ゲームの **げんき⚡（スタミナ）** になる。つなぎ方は [BRIDGE.md](BRIDGE.md)。

## あそびかた（いまできること）

1. **いえを かたづける**：おじいちゃんから受け継いだ ほこりだらけの家。がらくた（10こ）を Aで持ち上げ、たんすに しまう。
   しまうほど家が明るくなり、3こめで **ぼろい つりざお**、6こめで **ちいさな むしあみ**、8こめで **さびた くわ**、10こめで おじいちゃんの手紙（50G）が見つかる。
   つりざおを見つけるまでは外に出られない。
2. **つりで おかねを かせぐ**：池の前で つりざおを使う → うきが しずんだら A → メーターの みどりで A。
   ぼろい つりざおは メダカ・タナゴ・フナ・ドジョウ。ふつうの つりざお（600G）で コイ・ナマズ・ウナギ。たまに あきかん・ながぐつ。
   釣った魚は 家の横の **しゅっかばこ** で売る。🎒の「さかな ずかん」に記録が残る。
3. **はたけを ひらく**：さくの中の くさ・いしを くわで どけて、たがやす。ポポばあちゃんの おみせで **じょうろ（150G）** と たねを買う。
   たねをまき、毎日 じょうろで水をあげ、ベッドで寝ると1日進む。水をあげた日だけ育つ（かれることはない）。

| やさい | たね | そだつ日数（水やり） | 売ると |
|---|---|---|---|
| かぶ | 20G | 3 | 50G |
| にんじん | 35G | 4 | 85G |
| トマト | 60G | 6 | 170G |
| かぼちゃ | 110G | 8 | 340G |

## げんき⚡（スタミナ）

- 実力テストの点数ぶん増える（上限200）。はじめて遊ぶときだけ 40 もらえる
- **寝ても回復しない**。0 になると「さんすうアプリで実力テストをやろう」と出る
- 減る量：がらくたを持ち上げる 1、つりざおを投げる 3、くさを かる 2、いしを どける 4、たがやす 3、たねまき 1、みずやり 2
  （歩く・売る・買う・寝る・しゅうかく は0）。`config.js` の `CFG.cost` で変えられる

## そうさ

- タブレット：左下の十字キー（指をすべらせて向きを変えられる）・右下の Aボタン・下のホットバーで道具をえらぶ。短く押すと向きだけ変わる
- キーボード：矢印 / WASD で移動、Space / Enter / Z で A、Q・E か 1〜9 で道具、Esc でとじる

## ファイル

| ファイル | 中身 |
|---|---|
| `config.js` | 数字とルール（げんき・魚・やさい・がらくた・見つかる道具）。調整はここ |
| `bridge.js` | さんすうアプリとのつなぎ・セーブ |
| `sprites.js` | ドット絵（画像ファイルなし、すべてプログラムで描く） |
| `world.js` | マップ（家の中 14×10、外 40×28） |
| `ui.js` | 会話・おみせ・もちもの・効果音（WebAudio） |
| `game.js` | 移動・片付け・釣り・畑・寝る・描画 |

## ためす

```
python -m http.server 8770 --bind 127.0.0.1
```

`http://localhost:8770/?dev=1` で開くと、☰メニューに おとな（テスト）メニュー（げんき+50を届ける・+500G・げんき むげん・家をぜんぶ片付ける）が出る。
